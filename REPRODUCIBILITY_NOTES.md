## Historical source-hash records

Some frozen result manifests were generated at an earlier point in the v1.6.5 runtime-fix history and therefore retain historical source hashes. They are preserved unchanged as provenance records and are not rewritten to match the later packaged source file. The final publication collector's `PACKAGE_MANIFEST.json` identifies the distributed source script by SHA256 `010da483...f581`.

The PEM-consistency runner intentionally validates the frozen scientific contract (VERSION and critical scientific functions) separately from a strict byte-for-byte historical source hash. This behavior is retained as part of the original research package.

## Forecast data

The repository includes the frozen issued-GFS cache used by the controller. This allows offline reproduction without reacquiring NOAA GRIB files. Fresh GFS acquisition is therefore optional and is not required for the standard reviewer workflow.

## Results policy

The repository contains manuscript-level results, dispatch outputs, stress-test results, PEM sensitivity outputs, scientific checks, and provenance. Very large raw solver-audit tables are intentionally omitted because their summarized solver/scientific checks are retained and the raw tables can be regenerated by the supplied code.

## No retuning

Reproduction must not retune the ExtraTrees model selection, GFS calibration/weights, uncertainty treatment, renewable-H2 accounting rule, or MPC objective using the held-out test period. The frozen runners encode these scientific locks.

## Historical absolute paths in frozen audit outputs

Some frozen `data_audit.csv` files retain absolute filesystem paths recorded
during the original simulations. These path fields are provenance metadata only
and are not required for execution. The reproducibility commands documented in
this repository use repository-relative paths. Frozen scientific result files
have intentionally not been edited solely to rewrite historical path metadata.
